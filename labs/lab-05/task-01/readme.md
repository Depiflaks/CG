# Вариант 3 — Компьютерный стол

Задание реализовано на TypeScript и WebGL2. Стол содержит три ящика с ручками,
боковые полки, полку для клавиатуры и подставку под монитор. Непрямоугольная
столешница с вогнутым передним краем построена веером треугольников; торцы
и нижняя поверхность замкнуты. Два точечных источника света дают диффузное
и зеркальное освещение, дополненное фоновым светом.

## Запуск

Из корня проекта:

```bash
npm install
npm run dev
```

Открыть `http://127.0.0.1:5173/#/lab-05/task-01` или выбрать задание в списке лабораторных.

## Текстура

Отдельная папка для изображений: `labs/lab-05/task-01/textures/`.
Файл текстуры дерева должен называться **`wood.svg`**.
Полный путь: `labs/lab-05/task-01/textures/wood.svg`.
Готовая текстура включена в задание; для замены положите свой SVG с таким же именем
и заданными шириной и высотой. Для PNG/JPEG измените импорт в `graphics/Texture.ts`
на имя соответствующего файла. Текстура загружается в WebGL и накладывается
по UV-координатам; используются mipmap и линейная фильтрация.

## Управление мышью — бонус

- Удерживать левую кнопку и перемещать мышь — вращать камеру вокруг стола.
- Колесо — приближать и отдалять камеру.
- Стрелки после щелчка по сцене — вращать камеру с клавиатуры.

Угол возвышения и расстояние ограничены, чтобы камера не проходила сквозь пол
и не попадала внутрь стола. При изменении размера окна пропорции сохраняются.
