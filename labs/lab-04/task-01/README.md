# Лабораторная 4, задание 1

Курносый додекаэдр: 60 вершин, 150 рёбер, 80 равносторонних треугольников и 12 правильных пятиугольников. Задание доступно по маршруту `#/lab-04/task-01` после запуска `npm run dev`.

Перетаскивание мышью или касанием вращает камеру вокруг центра объекта. Колесо изменяет расстояние до объекта, стрелки вращают камеру с клавиатуры. Кнопка сбрасывает положение камеры. Ползунок задаёт непрозрачность от 0 до 100%, флажок включает освещение.

Координаты вычисляются через золотое сечение и действительный корень кубического уравнения. Пять исходных точек порождают вершины циклическими перестановками координат и сменой чётного числа знаков. Формулы и контрольные характеристики: [модель Дэвида Маккуи](https://dmccooey.com/polyhedra/RsnubDodecahedron.html), [математические данные](https://dmccooey.com/polyhedra/RsnubDodecahedron.txt). Координаты нормированы к единичной описанной сфере. Грани восстанавливаются по опорным плоскостям и обходятся против часовой стрелки снаружи. Цвет назначается по смежности; общие рёбра рисуются один раз, диагонали триангуляции не выводятся.

Приложение использует WebGL2 в соответствии с браузерной архитектурой проекта. Фиксированного конвейера `GL_LIGHTING`, `glLight` и `glMaterial` в WebGL нет: освещение реализовано шейдерами по модели Фонга с плоскими нормалями граней, точечным источником света, фоновой и диффузной составляющими, бликами материала. Для обратных сторон нормаль инвертируется.

Для полупрозрачности включены тест глубины и смешивание `SRC_ALPHA`, `ONE_MINUS_SRC_ALPHA`. Сначала рисуются непрозрачные чёрные рёбра с записью глубины. Затем запись глубины отключается и выпуклый объект выводится двумя проходами: отбраковка лицевых граней, затем отбраковка обратных. После этого запись глубины восстанавливается. При непрозрачности 100% грани рисуются с записью глубины, затем видимые рёбра. Смещение глубины заполненных граней устраняет мерцание рёбер.

Код разделён на геометрию, камеру и управление, ресурсы WebGL и рендеринг, интерфейс и жизненный цикл приложения. При уходе со страницы освобождаются буферы, шейдерная программа, обработчики и наблюдатель размеров. Потеря контекста WebGL обрабатывается с повторным созданием ресурсов при восстановлении.
