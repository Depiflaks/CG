Текстуры загружаются из PNG-файлов в этой папке.

| Файл | Назначение |
| --- | --- |
| brick.png | Кирпичная стена |
| stone.png | Каменная стена |
| wood.png | Деревянная стена |
| metal.png | Металлическая стена |
| tile.png | Стена из плитки |
| sandstone.png | Стена из песчаника |
| floor.png | Пол |
| sky.png | Небесная сфера |
| shadow.png | Карта затенения стен |

Для замены текстуры замените соответствующий файл и обновите страницу.
Текстуры стен, пола и неба должны иметь одинаковые размеры: текущие изображения — 256 × 256 пикселей.
Карта затенения может иметь другой размер. Белые участки сохраняют яркость, тёмные затемняют стену; низ изображения соответствует основанию стены.
Пути к файлам и порядок материалов заданы в `../graphics/materials.ts`.
