Текстуры загружаются из PNG-файлов в этой папке.

| Файл | Назначение |
| --- | --- |
| brick.png | Кирпичная стена |
| stone.png | Каменная стена |
| wood.png | Деревянная стена |
| metal.png | Металлическая стена |
| tile.png | Стена из плитки |
| sandstone.png | Стена из песчаника |
| floor.png | Пол |
| sky.png | Небесная сфера |

Для замены текстуры замените соответствующий файл и обновите страницу.
Текстуры стен, пола и неба должны иметь одинаковые размеры: текущие изображения — 256 × 256 пикселей.
Затенение вычисляется в шейдере: цвет умножается на коэффициент освещения и затемняется у основания стен.
Туман смешивает цвет поверхности с цветом дымки, плавно усиливаясь на расстоянии от 2 до 12 единиц.
Пути к файлам и порядок материалов заданы в `../graphics/materials.ts`.

Картины загружаются из `paintings/mountains.svg`, `paintings/sailboat.svg` и `paintings/flowers.svg`.
Все картины должны иметь одинаковые размеры; текущие изображения — 256 × 256 пикселей.
Их размер может отличаться от размера текстур стен. Для PNG укажите новый путь в `PAINTING_URLS` и соответствующем импорте в `../graphics/materials.ts`.
Второй текстурный массив привязан к текстурному блоку 1 и смешивается с материалом стены по прозрачности изображения.
Картины размещаются на части вертикальных стен; пол, верх стен и небо не декорируются.
